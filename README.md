# Voice Type

Голосовой ввод и голосовые команды для Linux (X11). Распознавание речи выполняется локально через [faster-whisper](https://github.com/SYSTRAN/faster-whisper), распознанный текст вставляется в активное окно через `xclip` и `xdotool`. Всё работает офлайн, без отправки аудио на внешние сервисы.

## Как это работает

Архитектура «демон + триггер»:

1. **Демон** (`--daemon`) запускается при входе в систему, один раз загружает модель Whisper в память и ждёт сигнала через именованный канал (FIFO) `/tmp/voice-type-trigger`.
2. **Триггер** (`--trigger`) мгновенно пишет байт в FIFO и завершается. Его удобно привязать к горячей клавише (например, F9): задержка на нажатие минимальна, так как модель уже загружена.
3. Демон записывает звук с микрофона до паузы, распознаёт речь и либо вставляет текст в текущее окно, либо выполняет голосовую команду.

Наличие демона позволяет не загружать модель при каждом нажатии клавиши, а также использовать настройки качества: модель `medium`, `beam_size=5`, VAD-фильтр, обрезка тишины по краям записи, русский `initial_prompt`.

## Возможности

- Локальное распознавание русской речи (faster-whisper, CPU или CUDA).
- Вставка распознанного текста в любое активное приложение.
- Голосовые команды: «сохрани», «копируй», «вставь», «отмени», «запусти» и др.
- Автозапуск демона при входе в систему (файл `.desktop` в комплекте).
- Режим `--debug` с индикатором уровня сигнала для настройки порога громкости.
- Подавление «галлюцинаций» Whisper (вырезание `[...]`, `(...)`), VAD-фильтр, обрезка тишины.

## Состав репозитория

| Файл | Назначение |
|------|------------|
| `voice-type.py` | Основной скрипт (демон, триггер, разовый режим) |
| `voice-type` | Bash-обёртка: задаёт `DISPLAY`/`XAUTHORITY` и запускает Python из виртуального окружения |
| `voice-daemon.desktop` | Файл автозапуска демона для `~/.config/autostart/` |
| `Makefile` | Установка (`make install`), окружение (`make venv`), проверка (`make check`), удаление (`make uninstall`) |
| `requirements.txt` | Python-зависимости для окружения `~/.venv/voice` |
| `INSTALL.md` | Подробная инструкция по установке и настройке |

## Зависимости

Системные пакеты (графическое окружение X11 — `xdotool` и `xclip`, Wayland не используется):

```bash
sudo apt install xdotool xclip
```

Python-пакеты (`faster-whisper`, `sounddevice`, `numpy`) устанавливаются автоматически командой `make install` в отдельное окружение `~/.venv/voice` из `requirements.txt` — вручную ставить их не нужно.

## Установка

```bash
make install
```

Команда создаёт виртуальное окружение `~/.venv/voice` и устанавливает Python-зависимости, затем создаёт `~/bin` и `~/.config/autostart` (при необходимости), копирует туда `voice-type.py`, обёртку `voice-type` и `voice-daemon.desktop`, подставив в `.desktop` реальный `$HOME` вместо жёстко прописанного пути. Удаление:

```bash
make uninstall
```

Проверить наличие системных зависимостей:

```bash
make check
```

При первом запуске модель `medium` (~1,5 ГБ) скачивается из интернета; повторные запуски используют кеш. Подробности и ручная установка — в [INSTALL.md](INSTALL.md).

## Использование

Запуск демона (обычно через автозапуск при входе в систему):

```bash
~/bin/voice-type --daemon --paste-keys ctrl+shift+v
```

Привязка триггера к горячей клавише в настройках ДЕ:

```bash
/home/nimda/bin/voice-type --trigger
```

После нажатия клавиши говорите вслух: демон завершит запись после паузы и вставит текст в активное окно. Если распознанная фраза совпадает с голосовой командой — вместо вставки выполняются соответствующие горячие клавиши.

Разовый запуск без демона (удобен для отладки):

```bash
~/bin/voice-type --debug
```

## Голосовые команды

| Фраза | Действие |
|-------|----------|
| сохрани / сохранить | `Ctrl+S` |
| запусти / запустить / старт | `F5` |
| отмени / отмена / верни | `Ctrl+Z` |
| копируй / скопируй / копировать | `Ctrl+C` |
| вырежи / вырезать | `Ctrl+X` |
| вставь / вставить | `Ctrl+V` |
| найди / поиск / найти | `Ctrl+F` |
| выдели все / выделить всё | `Ctrl+A` |

## Основные параметры

| Флаг | По умолчанию | Описание |
|------|--------------|----------|
| `--daemon` | — | Режим демона: модель в памяти, ожидание сигнала |
| `--trigger` | — | Разбудить демон (привязывается к клавише) |
| `--model` | `medium` | Модель Whisper: `tiny`, `base`, `small`, `medium` |
| `--device` | `cpu` | `cpu` или `cuda` |
| `--compute-type` | `int8` | Тип вычислений |
| `--language` | `ru` | Язык распознавания |
| `--beam` | `5` | Beam size (точнее, чем 1) |
| `--no-vad` | — | Отключить VAD-фильтр (по умолчанию включён) |
| `--threshold` | `0.010` | Порог громкости при записи |
| `--silence` | `1.2` | Секунды тишины, завершающие фразу |
| `--max` | `20.0` | Максимальная длительность записи (сек) |
| `--paste-keys` | `ctrl+shift+v` | Клавиши вставки текста |

## Файлы времени работы

| Путь | Назначение |
|------|------------|
| `/tmp/voice-type-trigger` | FIFO-канал «триггер → демон» |
| `/tmp/voice-type.log` | Лог демона |
| `/tmp/voice-type.pid` | PID демона |

## Диагностика

```bash
tail -f /tmp/voice-type.log          # лог демона
pgrep -af "voice-type.py --daemon"   # проверка, что демон запущен
cat /tmp/voice-type.pid              # PID демона
```

Типичные проблемы:

- **Триггер молчит** — демон не запущен: `~/bin/voice-type --daemon`.
- **FIFO «зависает»** — удалить канал и перезапустить демон: `rm /tmp/voice-type-trigger`.
- **Срезаются начало фразы или слова** — подобрать порог: `~/bin/voice-type --debug`, затем увеличить `--threshold` (обычно в диапазоне 0.005–0.020).
- **Текст не вставляется в терминал** — терминалу нужен `ctrl+shift+v` (передаётся через `--paste-keys`).
