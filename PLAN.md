# План исправления голосового ввода (F9 → voice-type)

## Диагностика

**Причина задержки:**
- Клавиша F9 привязана (Cinnamon, `custom1`) к запуску процесса заново:
  ```bash
  /home/nimda/bin/voice-type --model small --paste-keys ctrl+shift+v --debug
  ```
- Каждое нажатие F9 порождает новый процесс, который **заново грузит модель Whisper** (несколько секунд на CPU). Запись начинается только после загрузки — речь, произнесённая в это время, теряется.

**Причины плохого распознавания:**
- `beam_size=1` — самый быстрый, но наименее точный режим Whisper (`voice-type.py:192`).
- Модель `small` слабовата для русского языка.
- Нет VAD/подрезки тишины на краях записи — в распознавание попадают комнатный шум и хвосты.
- Нет `initial_prompt` с подсказкой русского языка.

## Решение

Выбрана модель: **medium + beam 5** (максимальная точность; распознавание на CPU — несколько секунд на фразу). Модель и `beam_size` выносятся во флаги, чтобы можно было откатить к `small + beam 5`.

### Архитектура: daemon + trigger

Модель держится в памяти постоянно; F9 лишь сигналит демону.

### 1. Переписать `~/bin/voice-type.py`

- Режим `--daemon`:
  - Грузит модель **один раз** при входе в систему (в автозапуске).
  - Создаёт FIFO `/tmp/voice-type-trigger`, ждёт на нём сигнал в цикле.
  - На сигнал: запись до тишины → распознавание → вставка/горячая клавиша.
- Режим `--trigger`: мгновенно пишет байт в FIFO («разбудить демон»). Именно его привязываем к F9.
- Параметры: дефолты `--model medium --beam 5 --compute-type int8`, `initial_prompt` на русском, `vad_filter=True`, подрезка тишины на краях записи.
- Защита от повторного запуска демона / «занятости» (если предыдущая фраза ещё распознаётся — новый F9 игнорируется).

### 2. Автозапуск демона

Файл `~/.config/autostart/voice-daemon.desktop` с `--daemon`.

### 3. Переназначить F9 в Cinnamon

dconf, ключ `/org/cinnamon/desktop/keybindings/custom-keybindings/custom1/`:
```bash
command: /home/nimda/bin/voice-type --trigger
```
(убрать `--debug`; логи демон пишет в `/tmp/voice-type.log`).

### 4. Настройка порога

Один-два прогона с `--debug`, чтобы замерить уровень фонового шума и выставить `--threshold` чуть выше него.

## Проверка после внедрения

- `voice-type --daemon` в терминале → в другой панели `voice-type --trigger` → запись должна начинаться мгновенно, качество русского текста заметно выше.
- Перезапустить демон, поправить F9, затем настроить автозапуск.
